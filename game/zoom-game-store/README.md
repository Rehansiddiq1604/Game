# Zoom Game Store

Welcome to the Zoom Game Store project! This application is designed to provide users with an engaging platform to browse and purchase games.

## Project Structure

The project is organized as follows:

```
zoom-game-store
├── src
│   ├── App.jsx               # Main application component with routing logic
│   ├── index.jsx             # Entry point of the application
│   ├── components
│   │   ├── Navbar.jsx        # Navigation component with links and search
│   │   └── Navbar.css        # Styles for the Navbar component
│   ├── pages
│   │   ├── Home.jsx          # Home page component
│   │   ├── Store.jsx         # Store page component displaying available games
│   │   ├── Categories.jsx     # Categories page component for game categories
│   │   └── Cart.jsx          # Cart page component displaying user's cart
│   ├── styles
│   │   └── global.css        # Global styles for the application
│   └── routes
│       └── AppRoutes.jsx     # Routing configuration for the application
├── package.json              # npm configuration file
├── .gitignore                # Files and directories to be ignored by Git
└── README.md                 # Project documentation
```

## Getting Started

To get started with the Zoom Game Store project, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd zoom-game-store
   ```

3. **Install dependencies**:
   ```
   npm install
   ```

4. **Run the application**:
   ```
   npm start
   ```

## Features

- Browse games in the store
- Search for games
- View different game categories
- Manage your shopping cart
